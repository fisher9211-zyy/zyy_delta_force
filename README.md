# Random Force+ — Public linked-source build

这是一个非官方《三角洲行动》玩家自制随机配装工具。

## 数据与图片来源

本版本故意保持简单：基础干员、地图、武器和装备数据，以及原项目已有的物品图片，在网页运行时直接读取 Random Force by Shotski 的公开 GitHub 项目资源。

- Original site: https://random-force.corke.dev/
- Original source: https://github.com/tomcorke/random-force

## 保留的自定义规则

- 地图仅 Zero Dam / Space City，概率 75% / 25%
- 移除所有手枪
- 移除 Tier 1 与 Tier 6 装备
- 移除 Tier 5 胸挂
- 装备 Tier 2 / 3 / 4 / 5 全选时概率 15% / 15% / 40% / 30%
- 多选装备等级筛选
- 新干员：蝶、液氮、回响
- 新武器：MCX、RM277、AR57、SVCH、刀
- 弹药等级：4 / 5
- 谁来改枪：自己 / 上家 / 下家
- 枪械改装预算：0 / 100K / 200K / 300K / 400K / 500K / 600K / 无限
- 自定义随机事件；无事件固定 50%，其他具体事件合计 50%
- 随机事件单击后立即出结果
